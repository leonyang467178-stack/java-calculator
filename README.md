# java-calculator
My first project, a simple calculator made with java

## Features
- Multi-number summation: Calculates the sum of N integers
- Factorial Calculation: Gives the factorial of a given integer
- Primality Test: Checks whether an integer is a prime number
- Multiplication Table: Generates and displays multiplication tables from 1 to 10
- Exponentiation: Calculates powers for integer inputs

## Build with
- Language: Java
- Standard Library: "java.util.Scanner"
